# Current manuscript figures

- `Main_figures/`: the supplied Figure 1 study-design image and the current data Figures 2, 3 and 4. Each data figure has a PDF, a 600 dpi PNG, a lossless 600 dpi TIFF and an editable SVG. Full captions are not printed inside the artwork.
- `Supplementary_figures/`: supplementary figures S1-S14. The former Figure 2C is `FigS14_language_direction`.
- `Captions/`: separate current captions, including definitions, denominators and treatment of missing responses.
- `Archive/Revision_options/source_data/`: earlier plotted values. Script 15 uses them only to check its recalculated values; they are not figures.

Regenerate the current main figures and S14 from the original CSV files with:

```r
source("Analysis_script/15_final_manuscript_figures.R")
```

Run this from the project folder. Audit results, raw-file hashes, plotted values, colour checks and the R session are in `Analysis_output/Final_figure_data/`.

Models are excluded separately for each dataset when more than 50% of their requests are API failures, matching the main analysis and manuscript. Exactly 50% is retained. Refusals and other unscored answers are treated as missing, not API failures.

Figure 1 is a supplied schematic and is not generated by this data-plotting script.
